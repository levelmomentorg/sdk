# Preview the supplied integration

Read [the partner handoff](partner-handoff.md). Run only the preview, test, or
build commands that it supplies. Do not invent a sandbox URL, endpoint,
password, credential, or SDK pin.

Use the handoff's target slot to check one terminal reward for a passed graded
break, no reward for a failed or abandoned break, cancellation, and a show
failure. Record the actual
environment and device used. A local check does not prove a native device
integration.
